# RegNet Cats vs Dogs Classification

## Overview

This project uses RegNetY-400MF pretrained on ImageNet to classify cat and dog images.

## Dataset

Dogs vs Cats Dataset

- 25,000 images
- 12,500 cats
- 12,500 dogs

## Model

- RegNetY-400MF
- Transfer Learning
- PyTorch

## Results

- Training Epochs: 5
- Validation Accuracy: 99.14%

## Technologies

- Python
- PyTorch
- Torchvision
- Matplotlib
- Scikit-learn
